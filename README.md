# MediTrack AI

« Des données de santé, un meilleur demain. »

Plateforme numérique intelligente destinée à améliorer la gestion des établissements de santé.

## Stack
- Frontend : React + TypeScript + Tailwind CSS
- Backend : Laravel (PHP) + API REST
- Base de données : MySQL
- IA : Python (Pandas, NumPy, Scikit-learn, PyTorch/TensorFlow)
- Outils : VS Code, Git/GitHub, Postman, Figma, draw.io, Docker

## Structure
- `backend/` : API Laravel
- `frontend/` : Interface React
- `docs/` : MCD, UML, maquettes, cahier des charges
